Complete corresponding source for the Stunt Race FX playable compatibility build.

frontend/ contains the Windows/libretro frontend and build helper.
bsnes-libretro/ contains the official bsnes libretro source snapshot at commit
260f5234410d0899f8446882c63d17f891b686e0.
