Complete source for the Stunt Race FX enhanced playable compatibility build.

frontend/ contains the Windows/libretro frontend and build helper.
snes9x/ contains the official Snes9x source snapshot at commit
7a8878f1306f65594c30b7d86dee41d972c2e495.
