STUNT RACE FX ENHANCED PORT - MILESTONE 2

This is an early Windows development build, not the finished 60 FPS native
port. It now has a corrected Super FX execution core, deterministic capture
tools, aspect-correct display, smooth framebuffer scaling, ultrawide-window
support, and fullscreen controls.

The ultrawide launcher currently centers the original 4:3 game picture in a
3440x1440 window. It does not yet render extra world geometry into the sides.
The smooth filter improves scaling; true polygon-edge antialiasing will arrive
with the native geometry renderer.

SETUP

1. Supply your own unmodified US Rev 1 ROM.
2. Put it beside this README and name it exactly:
   Stunt Race FX (USA) (Rev 1).sfc
3. Double-click Play Enhanced.cmd, or Play Ultrawide 3440x1440.cmd.

Expected ROM MD5: 128b316a74caf17fdc216b3ab46d4a9a

CONTROLS

F11 or Alt+Enter  Toggle borderless fullscreen
1                 Corrected 4:3 aspect
2                 Raw framebuffer pixel aspect
3                 Stretch to fill the window

No ROM or Nintendo-owned game data is included in this package.
